# 遮挡选路有限诊断 — 2026-11-02

## 决定

**当前场景不支持核心主张。停止，不启动策略训练。**

场景可以演示“侧移以揭示遮挡”，但这次有限检查没有发现拍摄与运动共同选择相对于普通侧移配自动曝光的额外收益。另有独立的学习路径问题：现有 warp_ste 无法提供揭示新内容所需的可靠方向信号。未更换渲染器、未扩大 seed、未修改冻结 checkpoint。

## 已交付

独立 `occluded_route` 场景及 `configs/gray_occluded_route.args`，实现原计划指定的几何、15Hz、8秒时限、真实命令队列、曝光积分和原 provisional 辐射模型。第一版几何即可完全遮挡初始封堵侧，未使用允许的几何修订。左右镜像使用共同目标，上下和侧面封闭，开放通道宽85cm。

`predict_exposure_motion` 在零未知外力假设下，通过实际动力学和执行器递推预测 E/G 命令首次生效时的状态。输入为当前运动状态、已有命令、新提议命令、相机延迟；未读取封堵侧、未来扰动或 `env.dg`。在0/1/2控制步相机延迟下，位置、速度、姿态与确定性执行一致。真实扰动下预测只是名义预测；目前逐步日志记录预测与下一步实际位置/速度。单步位置误差为0是离散位置更新尚未受新扰动影响的结果，不能解释为真实未来运动预测无误。新配置显式启用对齐意图；旧配置和 checkpoint 默认仍使用原有意图。预测和实际未来运动不能混称。

## 闭环结果

开发8个、确认8个episode，每组均衡覆盖左右封堵与亮暗；35个开发组合。确认候选在运行前由开发结果固定，未按确认episode真实答案选优。观察窗口1.6秒，随后根据图像诊断判定封堵侧，交给共同的路线跟踪器。灰度判断使用48×36分辨率。

| 开发集锁定的确认条件 | 选路正确 | 到达成功 |
| --- | ---: | ---: |
| 右侧移 + E=.03/G=.02 | 8/8 | 8/8 |
| 右侧移 + mean-AE | 8/8 | 8/8 |
| 保持 + E=.03/G=.02 | 4/8 | 4/8 |
| 右侧移 + E=.30/G=.02 | 8/8 | 8/8 |

初始左右封堵的无噪声图像完全相同；保持观察时读图器打平，使用预定平衡规则猜测，没有读取真实答案。侧移后出现可区分图像。长曝光E=.85在亮场景失去部分判别能力，开发集侧移组合为6/8；多种较短固定曝光和自动曝光都为8/8。相机设置能影响选路，但当前无需复杂的联合选择。

这不是自主飞行策略结果：读图器使用两种布局的仿真模板以及真实姿态、光照和当前E/G；跟踪器使用预定路线。特权仅用于诊断场景与物理收益，未作为策略训练数据。所有比例只属于8episode工程筛选，不是算法优劣或泛化统计。

## 学习路径检查

在真实24步侧移动力学后，用左右布局的无噪声辐照图差异作为可见信息诊断量。动作尺度0.5和1.0处，有限动作差分分别约0.01663、0.00783，而 warp_ste 的对应 autograd 分别约1.3e−18、−5.6e−12。两者严重不一致；起点完全遮挡时有限小扰动和梯度都为零。

这支持“当前局部warp近似遗漏了新显露内容”的判断，不是任务梯度验证，也不证明任何可微学习方法不可能解决遮挡。即使今后解决这个梯度问题，也不能把本场景变成已有联合优势的证据。

## 下一项唯一优先事项

**先确定一个确有相机—运动联合任务收益的物理机制，暂不训练本场景，也不先开发遮挡可微渲染器。** 本轮证明普通侧移加自动曝光已足够，不能为了得到预期结论继续增加噪声、收紧期限或削弱对照。下一轮应先提出一个具体、可检验的物理假设并限定小测试，而非直接扩大训练。
