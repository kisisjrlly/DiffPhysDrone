# 项目现状与后续方向（2026-11-08）

## 结论先说

当前项目已经证明了“导航任务损失可以通过可微成像过程学习曝光/增益”。当前项目还没有证明“相机设置和飞行动作可以联合选择”。后一个问题在现有窄缝配置中不能继续靠换网络、换优化器或增加训练预算解决，因为本轮的两个前置条件都没有成立。

本报告把两件事分开：已经有证据的相机学习结果，以及尚未具备实验条件的拍摄—运动联合结果。

## 本轮实际完成的工作

在分支 `codex/imx900-intent-closed-loop` 上，已经实现并检查了：

- 残差联合网络：同时输出飞行修正和相机修正；
- 长曝光研究 profile、曝光历史积分和相机命令时间线；
- 交互探针、可达性诊断、四组前置门和训练门禁；
- 底座对照、固定曝光/速度读图网格、噪声与饱和记录；
- 结果哈希、源码快照和复核配置保存。

当前源码测试为 **304 passed**。测试通过只说明软件接口和门禁行为正确，不说明联合学习假设成立。

## 两个门的结果

### 1. 飞行底座门失败

历史混合光照 checkpoint 在自己的旧任务上可以飞，但它是在 `single_wall_slit`、起点 `-1.5 m`、60 步、单帧成像条件下训练的。

本轮要求的 `joint_slit`、起点 `-2.5 m`、90 步、时间积分条件下，开发集结果为 **0/32**。因此残差网络的改进无法解释为“学会了更好的拍摄配合”；它首先必须重新学会飞过当前任务。

这不是相机学习失败，而是底座与目标任务不匹配。

### 2. 曝光—运动交互门失败

在扩展曝光和速度网格上：

- 最好曝光没有随速度改变；
- 交互统计 `z=1.78`，低于预设的 `2.0`；
- 另一种 log-loss 读数的交互项为负号，不能与准确率读数相互确认；
- 长曝光主要造成饱和，未显示出稳定的速度相关收益；
- 实际时域模糊量约 `6.55e-4`，相对于图像信号约 `0.07%`。

所以当前相机模型中没有可可靠学习的“快飞时短曝光、慢飞时长曝光”关系。50 ms 只是研究近似上限，不是硬件标定结果，也没有解决这个问题。

## 已经得到的较强正面证据

主灰度线的冻结飞行实验支持以下较窄的结论：

- 正常灰度图训练：69/100 成功；
- 同一模型置零图像：1/100；
- 独立盲模型：4/100；
- 五个训练种子中，保留导航损失到相机的梯度约 69.45%，切断该梯度约 3%。

这些结果支持“任务驱动的可微曝光/增益控制”。它们使用冻结飞行策略，不能写成相机与飞行动作的联合收益。

当前使用的 calibration 仍标记为 `calibrated:false`，因此这些结果是 provisional simulator 结果，不能作真实 IMX900 性能或真机泛化声明。

## 为什么过去一直卡住

过去反复更换场景和学习算法，实际上一直在试图用算法补足实验条件中不存在的因果关系：

1. 窄缝任务的飞行底座和新窄缝任务不一致；
2. 当前 15 Hz、48×36 输入和曝光范围产生的运动模糊太小；
3. 长曝光带来的主要变化是饱和，而不是随速度变化的可利用信息；
4. 因此自动曝光、固定曝光和联合相机—运动策略没有稳定的可分任务；
5. 继续改 PPO、GRPO、BPTT、网络宽度或训练预算，只会增加不可归因的结果。

这解释了为什么许多训练和场景尝试都以“无区分度”或“无法归因”结束。

## 项目现在应该怎么走

### 近期：结束当前联合实验线

不要启动残差联合训练的 A–F 六组。保留失败门结果，不把它写成“联合学习已经被否定”，而是写成：

> 当前窄缝任务和 provisional 相机模型没有形成足够强、可归因的拍摄—运动交互，因此本轮不能检验联合学习。

如果目标是尽快完成论文，主线应收束为“任务驱动的可微曝光控制”，使用已经完成的 full/detached、正常图像/零图像和自动曝光对照。

### 以后：若必须坚持联合拍摄—飞行主张

应当另开一个物理模型和任务版本，顺序固定为：

1. 先让成像模型在合法工作范围内产生可解释的速度相关观测差异；
2. 用不训练网络的四格实验确认最佳曝光确实随飞行方式改变；
3. 再为同一任务训练可微联合策略；
4. 若四格实验没有交互，立即停止该版本，不换算法制造结果。

这属于新的实验线，不能继续复用当前失败底座并把它称为联合学习。
