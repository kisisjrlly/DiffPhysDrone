# 后续路线：在一个小闭环里学习拍摄与运动

状态：路线设计，尚未实施。本文件没有授权自动启动训练，也没有把历史未完成的联合比较记为完成。

## 1. 要交付什么

在同一个窄缝任务中，得到一个可重复的闭环比较：普通自动曝光配运动学习、只学习拍摄、联合学习拍摄与运动。若联合方法有收益，要用交叉执行说明收益来自两者配合，并核对可微相机信号的作用。

这条路线的变化是：稳定控制器负责基本飞行，图像估计器负责从照片读取相对缝位置，只学习少量运动安排和相机参数。相机参数使用可微成像梯度；运动参数使用成对真实仿真试跑。它不更新完整飞行网络；相机更新仍涉及闭环反传，不能因为运动参数使用试跑，就宣称已经绕开运动到图像的近似导数。保留路径和限制见第4.2节。

这能减少同时学习所有模块的风险，不能保证联合方法一定优于强自动曝光。

## 2. 当前证据与需要纠正的判断

- 历史灰度飞行和冻结飞行的相机学习已有记录，但不是联合收益证据。
- `single_wall_slit_diff` 已存在。8 个旧样本中，旧版本和该版本都是 4/8，逐 episode 的成功/停止原因一致。这只是小样本结果一致，不是逐帧、逐动作等价证明，也不是新相机 profile 下的能力证明。
- 当前 `audit_proof_camera.py` 的动作不读取图像；它记录运动中的单帧，再用离线分类器评分。因此它不是图像驱动的穿缝闭环。
- 该工具给不同曝光/速度单元使用不同 episode seed；同一控制步在不同速度下还对应不同距离。不能把这些结果当成匹配状态、匹配噪声的曝光—速度因果比较。
- 现有 proof profile 把 read noise 从原值 .005 改成 .03，并在饱和前按曝光补偿亮度。后一个操作绕开了原来的电荷/输出饱和限制。该配置可以作为抽象软件模型记录，不能当成正常相机物理已经修复的证据。
- 当前四组脚本的 D 同时切掉相机参数梯度和运动观察梯度，不能单独归因给相机梯度。
- 最优曝光不翻转、全图平均图像差很小，都不足以证明闭环不存在交互。相机曝光短于控制周期，也不意味着曝光期间没有运动。

保留上述代码和数据，不覆盖。它们不继续充当本路线的训练许可或任务结论。

## 3. 一个任务、一个相机版本、一个控制接口

### 3.1 任务

复用旧单墙窄缝的几何与分布，通过显式 `single_wall_slit_diff` 入口运行：

- 起点 x=-1.5m，墙 x=0，目标 x=1.5m；15Hz、60步；
- 96×72 成像、48×36 两帧输入；缝宽、机体半径、动作限幅沿用旧配置；
- 暗光、亮光、暗转亮、亮转暗，沿用旧照明规则；
- 飞行命令两步队列、原执行器与球体连续碰撞；
- 仅学习平面内接近与横向对准安排，高度交给固定控制器。高度不瞬移，实际动力学与运动引起的姿态变化仍参与成像；
- 目标不提供缝位置，所有方法共享布局、初态和外部随机样本。

这是一个简化的机制实验。通过后才讨论完整三维策略与现有无人机部署，不能把它直接写成真机结论。

### 3.2 成像

统一使用一个单独的、`calibrated:false` 的 0.1–50ms 研究 profile。曝光范围来自已有研究版本，不声称是实测 IMX900/D455 控制范围。保留原增益、噪声系数和照明，不使用 proof profile 增大的读出噪声。

成像顺序必须固定：实际运动历史中的九个曝光采样 → 辐照积分/电荷 → 噪声与增益 → 饱和/响应与量化 → 原图像预处理。若实现电荷满阱限制，必须与输出端限幅分开记录，不能把二者混称为一个已标定过程。

- 九点时间积分后每帧只施加一次噪声，不叠加 box blur。
- 不在饱和前除以曝光来避免过曝，不增加额外输入归一化。
- 使用实际横向、前进和旋转投影计算缝边缘位移。不能将前进速度直接当成横向像移速度。
- 50ms<66.7ms，所以本版本每控制周期仍是一帧；不宣称长曝光减少帧数。
- 比较组使用相同相机更新约束、初始物理 E/G 和命令时序。

曝光、噪声、照明不能按成功率调整。长曝光若没有用，保留这个结果，不再把上限往外扩。

### 3.3 图像与控制

闭环只有一条：

```text
两张真实含噪灰度图 → 估计相对缝方向/横向偏差
                  ↓
运动安排参数 → 固定跟踪控制器 → 命令队列/执行器 → 实际运动
                  ↓                                  ↓
相机参数 ← 当前图像、机载运动信息和待执行命令 ← 下一张图像
```

采用一个共享小 CNN（通道8/16/32），先用固定采集的仿真图像监督拟合一维相对缝方向，再冻结。训练标签允许来自仿真几何；执行时只能使用图像和已有机载状态，不使用真实缝位置、深度、光照标签或答案模板。共有读图器准备的成本单独计入总预算。

在原有最多128条采集轨迹内，预先登记曝光、增益、四类光照、接近距离、横向偏差和实际运动的覆盖安排，不能只在默认曝光下采集再假定能读取所有合法设置。按整条轨迹划分拟合/检查数据，不能把相邻帧随机拆分当成独立检查；开发和确认飞行的图像不得反向用于拟合。冻结后保存权重与数据划分hash。所有方法同时记录逐步估计误差，并按曝光、距离和运动分组报告，便于区分读图失误与控制失误。不增加第二个读图器，也不按联合组结果重训它。若覆盖有限，必须披露未覆盖范围，不能把1000次更新称为能力保证。

固定控制器只根据估计偏差与机载运动状态执行对准。仿真真值只用于读图器训练标签、控制参考和事后评分，不进入相机或运动决策。

首版两帧一致性可以作为反馈特征，不引入一个新的不确定性网络或 Critic。

## 4. 学习什么，怎样学习

### 4.1 小参数策略

运动参数最多6个，控制接近速度、按图像偏差减速的程度、稳定观察的程度及横向修正安排；底层跟踪增益固定。相机参数最多6个，控制对自动曝光建议的曝光/增益修正，输入为图像摘要、当前运动和可因果获得的待执行命令。

参数表示的是可根据每一帧改变行为的反馈规则，不能是一条按真实布局单独优化的开环轨迹。每个 episode 使用同一组参数，不读取 episode 编号选动作。

### 4.2 明确学习信号及其近似范围

- 相机：对完整图像闭环的导航损失反传，只更新相机参数。冻结读图器权重仍保留对其输入的导数。
- 运动：同一批 episode 与随机样本，执行 θ+δ、θ−δ，按完整任务代价估计运动参数的更新方向。正负试跑全部计入预算。
- 两者优化同一个导航目标，并在同一套闭环里交替更新；不提供“正确曝光”“正确观察动作”的教师标签。
- 相机更新默认保留原闭环计算图，不以隐藏的detach切掉位置反馈来回避问题。曝光改变照片、照片改变动作、动作改变后续位置、位置改变后续照片，这条路径仍会用到现有渲染近似。运动参数使用试跑只改变运动参数的更新方式，不保证相机梯度可靠。

实现时随运行协议保存一张实际梯度路径表，逐项标明：E/G到曝光积分与传感器输出、冻结读图器对像素的导数、控制器与命令队列、动力学到导航代价，以及位置/姿态到后续图像。分别注明实际实现、保留或切断的位置、STE或warp等近似；不得将近似标成精确物理导数。不得静默忽略曝光时长对积分采样位置和模糊的影响。

梯度核对并入同一程序的集成正确性检查：固定外部随机样本，在已采集轨迹中包含静止、实际横向/转动与长曝光的代表状态，比较解析/代理方向与前向有限差分，记录步长、原始结果和不一致路径。平滑状态一致不能替代硬可见性、饱和或终止边界的说明；不能只用静止例子通过后宣称所有飞行状态有效。核对失败时先定位实现错误与近似局限，只在既定修复预算内处理；未解决则如实报告梯度路径未就绪，不能把无效学习信号下的失败当成联合价值为零。

结论最多写“可微相机指导拍摄，试跑反馈学习运动”。是否能够做到，要由实现及结果支持；不能写成运动观察梯度已被证明有效，也不能写成已完全避开该问题。

这是针对当前证据作出的实现选择，不代表已经证明该混合方法优于 PPO、GRPO 或完整 BPTT。

### 4.3 目标必须允许减速

取消把固定前进速度作为主要训练目标的设计。否则“减速以获得信息”会在优化时受到额外惩罚，而最终评价又要求它有用。

训练代价只包含终点未到达、几何碰撞风险、已用时间和动作代价。各项先按距离/时间/动作范围归一化，在控制与读图准备期间锁定一次。梯度相机与无梯度对照使用同一个连续代价；最终按实际安全到达优先，其次失败按完整时限计费，再比较动作代价。

连续代价下降而实际成功不提高时，报告目标未对齐，不增加另一轮损失调参。

## 5. 一次完整比较

四种比较类型，实际最多六个优化运行：

| 类型 | 相机 | 运动 | 作用 |
|---|---|---|---|
| A1/A2/A3 | 平均亮度AE、梯度AE、运动感知AE各一组 | 学习运动安排 | 强自动曝光对照 |
| B | 学习相机 | 固定共同运动安排 | 单独拍摄学习 |
| C | 学习相机 | 学习运动安排 | 联合候选 |
| D | 学习相机与运动，全部使用成对试跑 | 学习运动安排 | 有替代学习信号的无梯度对照 |

运动感知 AE 读取同样的图像与机载运动信息，在亮度建议上限制预计缝边缘像移，并在合法范围内调整增益。它的规则与所有更新上限在开发前锁定，不能把平均AE故意调慢。

所有组共享读图器、控制器、参数初值、样本顺序、相机与飞行约束。相机残差初始为零；实际初始物理 E/G 一致。不同类型可训练参数数不同，如实报告；C/D 的参数化必须相同。

A类按开发集选出一个自动曝光方案并锁定。确认集不能每个 episode 选最好的AE，也不能按其结果修改候选。

仅在 C 形成收益候选时，增加确认集的固定交叉执行，不再训练：C的拍摄配A的运动，C的运动配同一个AE。完整2×2结果与时间线用于判断是否真的配合，而不是只比较两个总成功数。

令 `S(运动,拍摄)` 为同一批确认episode的安全到达率，定义：

```text
I = S(C运动,C拍摄) - S(A运动,C拍摄)
  - S(C运动,AE)    + S(A运动,AE)
```

配合证据要求 `I >= 4/64`，且C改变拍摄和改变运动的两项交叉回退都降低成功数。这是工程筛选规则，不是证明所有独立方法都达到了各自最优。相机规则在交叉执行中仍根据当下实际图像和运动运行，不能回放原轨迹上的曝光序列冒充闭环。

交叉后变差也可能包含模块输入分布改变，不能单凭这一项宣称已经证明“为下一次决策主动测量”。使用同一2×2执行已有时间线，在开发集按预定episode编号选择代表例，并在确认集完整报告对应结果：需要哪次对准信息、请求何种拍摄/运动改变、何时实际生效、估计误差何时改善、影响哪次后续命令与安全到达。真值误差只用于事后解释。无法追踪这条因果顺序时，结论限于该组合的任务收益，不扩大为预见性测量机制；不再追加新场景或额外组合。

相机梯度单独切断只作为前向一致性/机制检查，不把失去主要学习信号的条件当作 RL 对手。

## 6. 固定投入，避免局部问题变成新项目

规划上限为4个工作日、24个单卡GPU小时。这是本轮投入上限，不是承诺届时必有正面结果。

| 交付节点 | 预算和产物 |
|---|---|
| 第1天 | 集成一个小闭环；共有采集最多128条轨迹、读图器最多1000次更新；控制器使用真值的参考仅做可执行性检查，不当方法成绩 |
| 第2–3天 | 六个优化运行，每组最多4096条完整rollout；正负扰动、选模验证、失败和重做全部计入各组预算；统一训练seed42 |
| 第4天 | 开发16个、确认64个固定配对episode；锁定规则一次；汇总实际任务结果、交叉执行与代表性视频 |

确认样本在运行前登记，检查是否已被历史实验使用；已使用的不能标为新的独立泛化证据。不按难度或成功情况挑选布局。

具体参数边界、损失系数、采集seed、数据划分和选模频率在第1天准备结束时写入运行协议；不能边看联合结果边改。若第1天无法闭合接口或基本控制，第1天的产物只能叫“准备未完成”，不得把它当成整个计划已经交付。

总预算的20%用于实现错误修复与受影响结果复跑。只修违背本协议的代码错误；修改场景、相机物理、网络和学习方法属于更换协议，不在本轮自动进行。超预算终止并保留完整账目，不另开“下一项唯一诊断”。

必要正确性检查合并到集成工作：真值不进入执行决策；记录不改变随机过程；相机噪声一次；动作/曝光时序一致；饱和不可被预补偿绕开；连续碰撞与机体一致；冻结读图器仍传输入梯度；相机扰动方向与固定噪声下的有限差分在平滑工况一致。结果比较的阶段不再新增研究门槛。

## 7. 怎样算完成，怎样报告

完成必须有同一闭环的全部预定比较和逐episode结果，不能用单帧分类、测试通过、报告提交或一个教师成功例子代替。

本轮工程收益候选要求：C在确认64次中，比开发集锁定的A与B均至少多成功8次，开发方向一致，且交叉执行满足第5节的配合判据。8/64是预先选择的工程尺度，不是显著性或发表门槛。阈值未达到时保留完整差异，不将小差异改写成完全无作用。

C与D回答可微相机是否在相同交互预算内带来学习收益。除最后结果外，报告按实际rollout次数和墙钟时间的学习曲线；D的正负试跑不能漏账。单seed结果不宣称最终方法优越性。

最后只能作以下对应陈述：

1. 联合任务收益与可微相机学习收益都有证据：交付机制实例，再决定论文规模的复验。
2. 联合任务收益有证据，但C不优于D：可以说配合有用，不能说可微学习更有优势。
3. 合法完整比较没有显示额外联合收益：该固定版本未支持主张，结束此版本，不改参数重找正面结果。
4. 准备或实现未完成：列出确切失败接口与已消耗预算，保留为工程未完成，不能说核心思想失败，也不能宣布计划完成。

第3项必须进一步按实际结果解释，不能全部写成“联合学习无效”：

- 自动曝光与联合组都很差：共同闭环/优化尚未建立足够能力，现有比较不足以判断核心思想；具体列出读图、控制与优化的已知证据，不猜唯一原因。
- 自动曝光已能完成大多数任务、联合组反而较差：本轮联合方案表现较差，不能将其笼统归咎于底座没有迁移。
- 各组几乎全部成功：本任务缺乏区分能力，不能从天花板结果推出联合选择没有价值。
- 有效完整比较存在差异但未达到工程阈值：如实报告差异和范围，不把“未达阈值”改写成完全没有作用。

第4项也包括关键梯度路径未就绪；这不是完成所有比较，更不是可微感知已被否定。4天/24GPU小时限制投入，不承诺在该时限内修复所有近似问题或获得论文结果。

交付一个运行入口、锁定协议、配置/源码/相机hash、完整任务表、逐步时间线、一段明确标注研究仿真的配合视频（仅在存在实例时）和一页中文结论。原分支、checkpoint和历史结果冻结，临时proof版本单独记录，不混入本轮新证据。

这条路线通过减少必须同时学会的东西、使用实际闭环结果并明确两种学习信号的局限来降低风险。仍然未知的是：在固定物理与任务下，联合选择是否有额外价值，以及现有相机梯度能否帮助学到这种价值。它们必须由完整对照回答，不能由计划本身保证。执行单位始终是这一个闭环的实现与比较，不再将每个局部问题扩展成新场景、新网络或另一条学习路线。
