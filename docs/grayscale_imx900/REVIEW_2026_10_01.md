# IMX900 experiment review — 2026-10-01

## Protocol fixes

Before long experiments, the response-surface evaluator was corrected to set
the E/G values on the built environment and to reuse the same episode seed for
each `(scenario, local_episode)` across all settings. Evaluation now restores
the checkpoint's `args.json` and calibration snapshot. The full/detached driver
now parses the reviewed `gray_camera_full.args` and
`gray_camera_detached.args`, verifies matched initialization/configuration
hashes, and aggregates success-rate differences by training seed.

Training loss alignment was corrected to pair `action[t]` with its own
`pre[t] -> post[t]` geometry transition. Camera smoothness uses the alive mask,
and training metrics use the first terminal event rather than a later padded
state.

## Fixed-camera response surface

The tuning scan covered the full `[0, 1]^2` action space at 0.10 spacing,
with five paired episodes per scenario. The provisional best mean setting was
`E=0.0, G=0.8`, with 20% mean success and 0% worst-case scenario success in
the small tuning sample.

An independent held-out evaluation used 100 episodes per scenario for that
selected setting:

| Scenario | Success | Collision |
| --- | ---: | ---: |
| dark | 4% | 94% |
| bright | 33% | 67% |
| dark-to-bright | 2% | 94% |
| bright-to-dark | 28% | 72% |
| overall | 16.75% | — |

This setting is not a robust fixed-camera baseline. The result supports
continuing with a state-dependent camera experiment, while remaining limited
to the provisional simulator and the frozen mean-AE flight checkpoint.

## Main causal experiment

The matched experiment completed for seeds 101, 202, 303, 404, and 505. Each
full/detached pair used 3000 camera-training iterations and 400 paired
evaluation episodes, with the same frozen flight checkpoint and the same
camera initialization hashes within each seed.

| Training seed | Full | Detached | Δ full − detached |
| ---: | ---: | ---: | ---: |
| 101 | 69.75% | 3.00% | 66.75 pp |
| 202 | 68.75% | 3.00% | 65.75 pp |
| 303 | 69.75% | 3.00% | 66.75 pp |
| 404 | 69.25% | 3.00% | 66.25 pp |
| 505 | 69.75% | 3.00% | 66.75 pp |

The mean training-seed difference is **66.45 percentage points** (standard
deviation 0.45 pp; five-seed t-based 95% interval approximately 65.90–67.01
pp). The direction is consistent in dark, bright, dark-to-bright, and
bright-to-dark episodes. The primary claim supported by this result is that,
under the provisional simulator and frozen flight backbone, navigation-gradient
access at the exposure/gain boundary produces a large and repeatable camera
learning benefit.

The result does not establish real IMX900 performance. The calibration profile
used by every run is still marked `calibrated: false`, and real sensor response,
command delay, and motion blur have not been measured. The machine-readable
manifest is at
`logs/imx900_full_detached_5seeds_20261001/experiment_manifest.json` and
contains checkpoint hashes, initialization hashes, evaluation seed ranges,
per-scenario rates, and paired bootstrap intervals.

Next, run one independent held-out paired evaluation with a new episode-seed
range. If the direction remains stable, freeze this simulator result and move
to measured IMX900 exposure/gain, noise, delay, and motion-blur calibration.
