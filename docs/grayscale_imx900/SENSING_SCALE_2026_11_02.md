# 图像大小与曝光—运动取舍检查 — 2026-11-02

**结论：两种大小均未发现预定尺度的曝光—运动取舍；停止，不启动训练，不扩大实验。**

本轮没有支持“48×36降采样掩盖了联合学习机会”的猜测。因此暂不提高策略输入分辨率。它也不证明所有场景、策略或真实相机都不受分辨率影响。

## 实际做了什么

复用原 `joint_slit` 的32布局参考跟踪检查，保持历史reset/dynamics seeds 291030/291031，结果仍为20/32成功。选取编号最小的成功episode（index=1），按预定规则取最接近墙前1m和0.4m的两个状态；轨迹与本地历史原始记录逐点一致，最大误差0。**这是特权参考跟踪器的成功轨迹，不是学习策略成功。**

场景几何、96×72传感器、100–8000µs曝光范围、噪声、gain与曝光积分均未修改。暗光/亮到暗、实际运动/静止、E=.10/.60/.85，G=.02，共24个成像条件；同一张含噪图只调用相机模型一次，然后送入48×36及96×72两条原预处理分支，获得48个读图结果。

复用固定规则ridge读图器，判断原有5mm缝位置差。每类32个拟合、32个独立检查样本；姿态±0.25°、纹理相位与光照±8%扰动沿用旧检查，跨条件共享噪声与扰动。没有拟合飞行/相机策略，读图结果不是导航成功率。

## 结果

下表为两种光照、三个曝光下的读图正确率范围；每项使用64个检查图像。

| 墙前位置 | 输入 | 静止 | 实际运动 |
| --- | --- | ---: | ---: |
| 约1m | 48×36 | 81.25–84.38% | 81.25–82.81% |
| 约1m | 96×72 | 75.00–82.81% | 76.56–82.81% |
| 约0.4m | 48×36 | 100% | 100% |
| 约0.4m | 96×72 | 100% | 100% |

“运动前后，长曝光相对短曝光的优势变化”最大仅**3.125个百分点**，未达到计划的10个百分点工程筛选尺度。无候选，因此未运行额外增益补偿。近处全部达到读图上限，不能分辨更细小差别；远处未达到上限，仍没有明确交互。96×72保留更多原始信息，但更高维的线性读图器在少样本下可能更难拟合，不能以表格证明大图没有可用信息。

E=.10/.60/.85对应890/4840/6815µs。位移按同一曝光期间平移与旋转投影计算，限于当前可见表面及恒定运动近似，**不是实测模糊核，也不包含新显露区域的精确变化**。这些数字表明受测轨迹中的曝光运动尺度较小，不足以证明整个模型“没有模糊”。

## 下一步决定

**暂不提高输入分辨率、不训练、不修改物理参数追求预期结果。** 本轮只排查了分辨率这一候选解释，没有选出新学习方法。下一轮若继续，需要先明确一种当前测试尚未覆盖的、可用合理物理尺度检验的任务取舍；不能把本轮局部负结果扩大成“可微感知无效”。
